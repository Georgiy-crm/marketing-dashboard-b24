# Маркетинговый дашборд — сделки Битрикс24

Автоматический дашборд по сделкам Битрикс24: по свежей CSV-выгрузке пересобирает метрики, генерирует выводы и рекомендации, отдаёт HTML для браузера и PDF для отправки.

## Проблема и решаемые задачи

Маркетинг ведёт партнер, который не работает в Битрикс24 и не видит данные CRM самостоятельно. Ему нужны регулярные, простые и наглядные отчёты о результатах привлечения лидов и продаж: сколько заявок приходит, какова конверсия, почему клиенты отказываются. Вручную готовить такие отчёты из выгрузок каждый день долго и подвержено ошибкам (как минимум однажды классификация сделок сломалась из-за кодировки файла).

## Пользователи

- **Основной** — партнёр, ведущий маркетинг: не работает в Битрикс24, нужны графики, дашборд и краткие выводы без жаргона Б24.
- **Второй** — маркетолог: работает с метриками и каналами, использует дашборд для оценки эффективности привлечения лидов.
- **Внутренний** — владелец бизнеса (ИП, внедренец Б24): собирает дашборд каждое утро по свежей выгрузке и отправляет PDF партнёру.

## Основная функция

Сервис автоматически строит дашборд по сделкам из выгрузки Битрикс24 (CSV за период) с привязкой всех периодов к дате последних данных в выгрузке (якорная дата), пересчитывает метрики, генерирует автоматические выводы и рекомендации по каналам привлечения и собирает PDF-версию для отправки.

## Формат результата

- **HTML-дашборд** `reports/dashboard-marketing_дд.мм.гггг.html` — открывается в браузере, публикуется по публичной ссылке (резервный канал доставки партнёру).
- **PDF** `reports/dashboard-marketing_дд.мм.гггг.pdf` — основной канал доставки партнёру (собирается из дашборда через headless Edge).
- Подробности по метрикам раскрываются в таблицах прямо в дашборде (блоки «Таблица — …»).

## Минимальный функционал  (первая версия) 

1. KPI верхнего уровня: заявки (штуки и суммы) за день / текущую неделю / текущий месяц / последние 30 дней.
2. График заявок по дням и в разрезе каналов (поле «Источник») и ответственных.
3. Конверсия в успех и в провал с расшифровкой по причинам отказа — в целом, по ответственным, по источникам.
4. Успешные сделки за день / неделю / месяц / 30 дней — количество и сумма; по дням (шт — синий, тыс. ₽ — зелёный).
5. Сравнение периодов: неделя vs прошлая, месяц vs прошлый, 30 дней vs 31–60 дней назад.
6. Тренды конверсии по каналам и ответственным (штуки и суммы по неделям).
7. Автоматические «Выводы и рекомендации» — какие каналы усиливать (генерируются скриптом по цифрам, без ручного дописывания).
8. Утренняя рутина: проверка папки `data` на файл с сегодняшней датой; есть — сборка дашборда и PDF, нет — краткое сообщение.

## Структура проекта

```
scripts/   — расчёт статистики и сборка дашборда (Node.js, без зависимостей)
skills/    — описание процесса сборки (routine, вызывается из Claude Code)
docs/      — обзор проекта
data/      — входные CSV-выгрузки «Сделки из Б24» (в репозиторий не включаются)
reports/   — готовые дашборды HTML и PDF (в репозиторий не включаются)
```

## Технологии

- **Node.js** (v24) — расчёт статистики и сборка HTML-дашборда, без внешних зависимостей .
  - `scripts/compute_deals_stats.js` — чтение CSV (автоопределение кодировки cp1251/UTF-8), классификация сделок (УСПЕХ / в работе / провал), агрегаты по периодам, каналам, ответственным; результат — `tmp/deals/stats.json`.
  - `scripts/build_dashboard.js` — рендер HTML-дашборда из `stats.json`.
- **HTML/CSS** — дашборд без фреймворков: светлая/тёмная тема, адаптив, раскрывающиеся таблицы, печатные стили для PDF.
- **Microsoft Edge headless** — генерация PDF из готового HTML (`--print-to-pdf` с `--user-data-dir` и абсолютными путями).

Python не используется (в целевой среде отсутствует) — вся логика нативно на Node.js.

## Входные данные

CSV-выгрузка «Сделки из Б24» из CRM (кодировка cp1251, разделитель «;»), кладётся в папку `data` с именем:

```
Сделки из Б24_дд.мм.гггг.csv
```

Каналы привлечения определяются полем «Источник»: Заявка из приложения, По рекомендации, Существующий клиент, Реклама в ВК, Рассылка E-mail, Вебинар онлайн, Сайт (CRM-форма).

## Запуск

```bash
node scripts/compute_deals_stats.js   # CSV -> tmp/deals/stats.json
node scripts/build_dashboard.js       # stats.json -> reports/dashboard-marketing_*.html
```

PDF собирается из дашборда через headless Microsoft Edge:

```powershell
powershell -File scripts/pdf_render.ps1
```
